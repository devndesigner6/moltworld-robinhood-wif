> **Current Robinhood rail:** chat-only x402 payments on Robinhood Chain mainnet (`eip155:4663`). WIF is the ERC-20 payment token with 18 decimals. Image, voice, video, marketplace, automatic refunds, and agent mandates are not enabled on this rail.

## For users: connect a wallet

You need a supported EVM wallet, WIF for the quoted payment, and a small amount of native ETH for gas if your first use requires a Permit2 approval. Connect through an injected wallet provider or WalletConnect; WalletConnect on a mobile browser requires the deployment's public Reown project ID to be configured. You authorize each chat call in your wallet; the current rail does not give an agent an unattended spending mandate.

<Steps>
  <Step title="Connect and switch networks">
    Open the [Moltworld Playground](https://motoworld-wif.vercel.app/playground), connect an injected or WalletConnect wallet, and switch to Robinhood Chain mainnet (`eip155:4663`).
  </Step>
  <Step title="Choose a chat model and quote">
    Submit a chat body to get a free quote. The quote shows the USD estimate and the exact WIF amount derived from the guarded live price snapshot.

    ```bash
    curl -s https://motoworld-wif.vercel.app/v1/quote \
      -H 'Content-Type: application/json' \
      -d '{"model":"gpt-4o","messages":[{"role":"user","content":"Hi"}],"max_tokens":200}'
    ```
  </Step>
  <Step title="Review and authorize the call">
    Submit the same body to the chat endpoint. The HTTP `402` challenge is authoritative. Review the token, network, recipient, and exact amount before your wallet signs it. Approve the exact WIF amount to Permit2 only when your wallet asks; that approval is a separate transaction.
  </Step>
  <Step title="Receive the response and receipt">
    After the signed retry succeeds, the response includes `Moltworld-Request-Id` and a signed `Moltworld-Receipt`. Use the request id with `GET /v1/receipts/{request_id}` to inspect the settlement.
  </Step>
</Steps>

## For developers: implement the x402 flow

Use an x402 EVM client that supports `ExactEvmScheme` and Permit2, or connect an injected EIP-1193 provider in your browser. The server returns a quote before payment and a quote-bound `Payment-Required` challenge for the exact request body.

```ts
const body = {
  messages: [{ role: "user", content: "Write a haiku about receipts." }],
  max_tokens: 200,
};

// Free preflight.
const quote = await fetch("https://motoworld-wif.vercel.app/v1/quote", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ model: "gpt-4o", ...body }),
});
console.log(await quote.json());

// Your x402 EVM client performs this sequence:
// 1. POST the identical body to the chat endpoint.
// 2. Decode the 402 Payment-Required header.
// 3. Ask the injected EIP-1193 wallet to authorize ExactEvmScheme + Permit2.
// 4. Retry the identical body with Payment-Signature.
const res = await x402Client.fetch(
  "https://motoworld-wif.vercel.app/v1/models/gpt-4o/chat/completions",
  { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(body) },
);
```

The WIF contract and all payment details come from the 402 challenge and [`GET /health`](https://motoworld-wif.vercel.app/health); do not hard-code a recipient or amount. Keep the request body byte-for-byte identical between the unpaid 402 request and the paid retry.

## Agent mandates: prototype, not live

The repository now contains an experimental EIP-1271 WIF session-mandate contract and local signer, but no contract is deployed by Moltworld and there is no wallet setup wizard on the website. A local Ganache test covers arm, signature policy, finite allowance, and revoke; it does not validate a real Permit2 deployment, facilitator, or Robinhood transaction, and the prototype has no independent audit. Do not fund it with valuable balances. The remote MCP remains keyless and can relay caller-signed chat but cannot autonomously pay. Automatic payment from an agent requires a compatible local stdio-MCP host, a separate session key, and an owner-armed on-chain mandate. Legacy Algorand LogicSig mandates, marketplace listings and payouts, media endpoints, and automatic WIF refunds are not Robinhood capabilities.
