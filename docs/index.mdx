Moltworld is an HTTP API for chat models. On the current WIF deployment, each chat request is priced from its exact body and authorized per call in WIF with an EIP-1193 wallet. Browser users can connect an injected wallet or, when the public Reown project ID is configured, WalletConnect on mobile. Successful responses include a signed receipt.

## What is live on Robinhood

- **A quote before payment.** `POST /v1/quote` returns the exact USD quote and quote-time WIF conversion for an eligible chat body.
- **Per-call wallet authorization.** The 402 challenge names Robinhood Chain (`eip155:4663`), WIF, the recipient, and the exact amount. The user's EIP-1193 wallet authorizes each call.
- **Permit2-aware EVM payments.** First use may require a separate exact WIF approval to Permit2 and native ETH for gas.
- **A receipt you can check.** Each successful paid response carries a signed `Moltworld-Receipt` tied to the request, response, WIF amount, and settlement transaction.
- **A deliberately small surface.** Image, voice, video, marketplace, automatic refunds, and agent mandates are not enabled on Robinhood.
